The Story of Tanda

In Mexico almost everyone has been in a tanda: ten friends chip in every week and each takes the whole pot once. Africa calls it susu, India chit funds, Korea gye. Hundreds of millions save this way.

And everyone knows the story of the organizer who vanished with the pot. So we asked: what if the pot sat in a contract that can only pay whoever's turn it is?

3

Benefits of Tanda

  • Nobody can run off with the pot
    • Not even the organizer
    • It only goes to the member whose turn it is
  • Everyone sees who has paid this round, on the chain
  • No account, no server: the share link is the tanda
  • Anyone can release a full pot, no key needed
    • Keeps working if the organizer disappears
  • Connect with WizardConnect (Paytaca) or pay from any wallet

BCH Usage
A CashScript covenant plus a mutable CashTokens NFT that counts the rounds.
13 tests in the BCH VM · a full 3-round tanda run on chipnet · ~200-byte contract
contract Tanda(bytes members, int n, int contribution, int maxFee, bytes32 category) {
  function payout() {
    require(tx.inputs[0].tokenCategory == category + 0x01);   // state NFT at input 0
    if (this.activeInputIndex == 0) {
      int round = int(tx.inputs[0].nftCommitment);
      require(round < n);
      bytes20 turn = unsafe_bytes20(members.split(round * 20)[1].split(20)[0]);
      require(tx.outputs[0].lockingBytecode == new LockingBytecodeP2PKH(turn)); // only whose turn it is
      require(tx.outputs[0].value >= n * contribution - maxFee);              // only a full pot
      require(tx.outputs[1].nftCommitment == bytes(round + 1));              // next round
      // ...money paid ahead stays in the contract; fees are capped (sums every input and output)
    }
  }
}

The Vision for Tanda

  • Stablecoin tandas in PUSD
    • Save in dollars, not in a volatile coin
  • Optional collateral, so members who already took the pot keep paying
  • Reminders and a public record of who pays on time
  • Remittances: families abroad join the same circle
  • Target: the next million savers with no bank account
